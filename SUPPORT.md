# Support

## Documentation

Start with the [README](README.md) for installation, configuration, API usage, authentication, database migrations, and deployment.

## Questions and bugs

For reproducible bugs, use the **Bug Report** issue template.

For proposed functionality, use the **Feature Request** issue template.

Before opening an issue:

- check the README;
- search existing issues;
- make sure the problem is reproducible with the current version.

## Security issues

Do not use public issues for security vulnerabilities.

See [SECURITY.md](SECURITY.md) for the private reporting process.

## Scope

This project is maintained on a best-effort basis. There is no guaranteed response time or support SLA.
